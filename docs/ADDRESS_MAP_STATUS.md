# D1600E A05 参数地址与证据状态

> 状态：只读整理；此表记录现有日志观察，不构成写入建议。不要向实机写入未验证值。

## 1. 先区分地址空间

- **PMBus 命令码**：例如 0x8B、0x8C、0xE1；这是总线事务中的 command byte。
- **固件文件偏移**：例如 payload 文件中的 0x144；用于定位二进制字节。
- **dsPIC 程序地址 / 指令字地址**：需确定 24-bit 指令打包方式及地址单位后才能映射。
- **RAM 变量地址**：必须由本固件反汇编、交叉引用和访问指令确认。
- **外设寄存器地址**：MCU 硬件外设地址空间，不能与 PMBus 命令码混用。

同一个十六进制数出现在不同地址空间，不代表它们是同一地址。

## 3. 电压控制地址：当前结论

- 现有证据**不足以确认** 0xE1 或 0xE3 是电压设定命令。
- “10000 mV → E3 = 67”“11000 mV → E3 = 45”只是日志中出现的映射文本，尚未证明它们对应最终实际总线写入帧、数据宽度、字节序或实测输出变化。
- 不能把其他型号/其他固件的 RAM 符号地址直接套用到 095HR5 A05。
- 在反汇编找到命令分发、参数存储、控制环使用路径并建立交叉引用之前，所有内部地址均标记为 **pending / unverified**。

## 5. 证据等级

- **Observed**：日志直接显示的值或行为。
- **Inferred**：由静态结构或调用关系推断，仍待交叉验证。
- **Verified**：由本固件指令级证据和独立验证共同支持。
- **Pending**：证据不足，不能用于写入或控制。
