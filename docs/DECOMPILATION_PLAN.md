# 全量反汇编与伪代码计划

1. 识别容器格式，提取 payload 并记录 SHA-256。
2. 确认 payload 头、记录宽度、指令端序和目标 MCU 变体。
3. 使用 Ghidra PIC/dsPIC 语言定义导入候选指令镜像；仍需验证具体镜像格式。
4. 验证 reset vector、interrupt vector、地址单位和代码区边界。
5. 自动分析后人工修复函数边界、跳转表、函数指针和外设寄存器。
6. 导出全量汇编、函数清单、调用图、交叉引用和每函数伪代码。
7. 从 I²C/PMBus 外设寄存器与 ISR 入手，恢复协议状态机和命令表。
8. 对 VOUT、OCP、OVP、UVP、PWM、ADC、风扇、温度、故障锁存逐条建立证据链。
9. 对所有结论标注：已验证 / 高可信推断 / 待验证。

禁止把未验证的标准命令候选当成固件已实现功能。
